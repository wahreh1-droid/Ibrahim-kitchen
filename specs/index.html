Core Feature

Daily Kitchen Dashboard روزانہ باورچی خانہ

The heart of the system. Every day the ledger is opened, a date is selected, and purchases, donations received, and consumption across three meal blocks are recorded — with opening and closing stock computed automatically.

Inventory Grid
Full per-day stock tracking
مکمل روزانہ اسٹاک

Each row is one food item. Columns cover Cost/Unit, Opening Stock, Purchased (Qty + Value PKR), Sadaqa received, three meal slots (Breakfast/Lunch/Dinner), and Remaining Stock — computed live from Opening + Purchased + Sadaqa − Consumed.

  • Column groups colour-coded: Purchased green, Sadaqa teal, Consumed yellow
  • Low-stock badge (LOW) appears when remaining stock falls below threshold
  • All cells autosave — no Save button required for individual entries
  • Opening balance auto-populated from prior day's closing stock

📅
Gregorian + Hijri Dates ہجری و عیسوی تاریخ

Both calendars shown simultaneously. The Hijri date can be corrected to follow Pakistan's moon-sighting — the engine pins the correction as an anchor and counts forward from it.

🔄
Carry-Forward Propagation آگے لے جانا

Closing stock automatically becomes the next day's opening. Editing an earlier day cascades correctly through all subsequent days — no manual re-entry needed.

⠿
Drag-to-Reorder Items ترتیب بدلیں

Desktop drag handles let the kitchen manager arrange items in any order. The order saves instantly and applies across all blocks, all days, and all reports.

👦👧
Three Meal Blocks بنین · بنات · خاص مواقع

Boys, Girls, and Special Occasions each have their own independent consumption grid. The Special block supports a per-day occasion title (e.g. ختم بخاری).

⭐
Temporary Items عارضی اشیاء

Items marked عارضی appear only on the day they are added. They don't carry forward — ideal for one-off purchases for a single occasion.

💰
Cost per Unit قیمت فی اکائی

Each item has a per-day price. PKR values compute automatically from quantity × cost. The price carries forward when a new day is created.

Donations & Qurbani

Donation Tracking قربانی و عطیات

A dedicated tab for recording all donations received by the madrassa kitchen — food items, cash contributions, and Qurbani — each linked to a donor name and date.

  • Add a donation with donor name, date, and an optional note
  • Each donation can have multiple line items — mix food items and cash in the same entry
  • Food items: free-text name, quantity, unit (Urdu dropdown), estimated value PKR
  • Cash donations: amount field only, no item fields required
  • Full edit mode — reopen any card and update all fields including item rows
  • Delete with confirmation; removing a donation removes all its item lines
  • Summary bar: total donations count, total cash received, total estimated value
  • Donations report with a date-range filter — exportable alongside the main kitchen report

Receipt Management

Photo Receipts رسید کی تصویر

Attach purchase receipt photos to any item for any day. Photos are stored securely and accessible only through the authenticated app.

  • Multi-select item picker — attach one photo to multiple items simultaneously (bulk attach)
  • Or manage each item's receipts individually from the "کھولیں" panel
  • Every photo passes through a built-in image editor before upload
  • Editor: crop with draggable handles, brightness slider, contrast slider, reset
  • Lightbox view — tap any thumbnail to see the full-size photo
  • Delete individual photos; storage cleaned up automatically
  • No-receipt note: when no photo exists, a reason can be typed (e.g. cash purchase, no receipt available)
  • Paperclip icon (📎) appears inline on grid rows that have photos attached

Input Method

Urdu On-Screen Keyboard اردو کی بورڈ

A full 46-key Urdu soft keyboard appears inline under any Urdu text field — no switching input method, no app install. Works on phones, tablets, and desktop.

  • Available in: Add Item, Edit Item Name, Occasion Title, and all Donations fields (donor name, notes, item names)
  • Each field has its own independent ⌨ toggle — open multiple keyboards at once in the donations modal
  • Inserts characters at the exact cursor position, respecting selections
  • Backspace removes one character or deletes a selection
  • Includes: ں ژ چ ٹ ڑ ڈ ص ث ظ ض ذ خ آ اً ۃ ؤ ء and SPACE
  • Modal does not scroll on each keystroke (preventScroll focus)
  • Hardware keyboard input works simultaneously — not blocked

Security

PIN Lock & Authentication قفل اور تصدیق

The app and its API are protected end-to-end. A 6-digit PIN locks the screen; a server-side signed token protects every data request.

  • 6-digit PIN — set on first run, stored as a PBKDF2-SHA256 hash (100k iterations) with a random salt. The PIN itself is never stored anywhere.
  • Every API request requires a server-signed session token. Hitting the backend URL directly without a valid token returns 401 — the data is not publicly readable.
  • 10-minute sliding idle lock: any activity resets the timer. 10 minutes of inactivity re-locks the screen automatically.
  • Manual lock: a floating 🔒 button locks immediately when the session is complete.
  • Session survives accidental page reloads within the 10-minute window.
  • Brute-force throttle: 5 wrong attempts trigger a 15-minute lockout. Remaining attempts shown after each wrong PIN.
  • First-run setup mode: screen prompts "6 ہندسوں کا نیا پن بنائیں" until the PIN is registered.
